Pre Test

  1. Jelaskan keudukan CSS dalam pemrograman web.
  2. Berikan masing-masing satu contoh penggunaan CSS selektor.

jawaban:

  1. CSS (Cascading Style Sheets) adalah bahasa stylesheet yang digunakan untuk mengatur tampilan dan tata letak dokumen yang ditulis dengan HTML. Dalam pemrograman web, kedudukan CSS adalah sebagai lapisan presentasi (tampilan), yang terpisah dari struktur dan perilaku halaman.
    Peran penting CSS dalam pemrograman web:
    1. Memisahkan konten dari desain, sehingga kode HTML lebih rapi dan mudah dipelihara.
    2. Menghemat waktu dan kode, karena satu file CSS dapat dipakai oleh banyak halaman web sekaligus.
    3. Memudahkan perubahan desain, sebab cukup mengubah satu file CSS untuk mengubah tampilan seluruh situs.
    4. Mendukung desain responsif, sehingga tampilan menyesuaikan ukuran layar (HP, tablet, desktop) melalui media query.
    5. Mempercepat loading halaman, karena file CSS dapat disimpan di cache browser.

Post Test

  1. Buat masing-masing satu contoh program untuk mengimplementasikan cara menulis CSS.

    2. jawaban:

    Ada 3 cara menulis CSS pada HTML: inline, internal, dan eksternal. Berikut satu contoh program untuk masing-masing.
    a. CSS inline ditulis langsung di dalam tag HTML menggunakan atribut style. Cara ini cocok untuk mengubah tampilan satu elemen secara cepat, tetapi kurang rapi dan sulit dipelihara jika elemennya banyak. Contohnya:
    h1 style="color: red; text-align: center;">Belajar CSS Inline /h1
    b. CSS internal ditulis di dalam tag style> pada bagian head> di file HTML yang sama. Cara ini cocok untuk satu halaman web saja, karena gayanya tidak bisa dipakai oleh halaman lain.
    c. CSS eksternal ditulis di file terpisah berekstensi .css, lalu dihubungkan ke HTML menggunakan tag di dalam . Cara ini paling rapi dan paling sering digunakan, karena satu file CSS bisa dipakai oleh banyak halaman sekaligus, sehingga perubahan desain cukup dilakukan di satu tempat.
